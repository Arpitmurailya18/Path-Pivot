Welcome to the Algorithm Visualizer

This quick guide shows you how to use both modes. You can reopen it anytime with How to use.

01

Sorting Mode

  • Choose Bubble, Selection, Insertion, Merge, or Quick Sort.
  • Use Array size and Speed to control the visualization.
  • Click Generate New Array for a fresh array.
  • Click Start to run. Use Pause and Reset whenever needed.
  • The highlighted pseudocode line shows what the algorithm is doing.
02

Pathfinding Mode

  • Choose BFS, DFS, Dijkstra, or A*.
  • Use Generate New Maze or build your own grid.
  • Set Start / Set End: click a cell to move the endpoints.
  • Draw Wall / Add Weight: click or drag on the grid.
  • Turn on Allow diagonal traversal if diagonal movement is wanted.
  • Click Start to search. Use Pause, Clear Visualization, or Reset as needed.
Tip: The colors in the legend explain what you see while an algorithm is running.
